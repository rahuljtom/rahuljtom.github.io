# Rahul Thomas Portfolio

A pixel-perfect minimalist, editorial portfolio.

## Deployment to GitHub Pages
1. Push this repository to the `main` branch of `rahuljtom/rahuljtom.github.io`.
2. Go to **GitHub Settings → Pages**.
3. Set the **Source** to the `main` branch and root `/`.
4. The site will be live at `https://rahuljtom.github.io/`.
